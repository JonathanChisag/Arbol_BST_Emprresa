## Descripción
Implementación de un Árbol Binario de Búsqueda (BST) en C++ para organizar empleados de una empresa usando su código como clave, representando la jerarquía de un organigrama empresarial.

## Funcionalidades
- Insertar empleados
- Buscar empleado por código
- Mostrar raíz del árbol
- Recorrido Inorden
- Recorrido Preorden
- Recorrido Postorden
- Calcular altura del árbol
- Mostrar nodos hoja

## Compilación y ejecución
```bash
g++ src/main.cpp -o arbol
./arbol
```
